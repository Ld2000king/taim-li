## מבנה

```
├── index.html          דף הבית (נכתב ידנית)
├── customer.html       ← נבנה מ־src/bis-live-customer.html
├── business.html       ← נבנה מ־src/bis-business-app.html
├── concept.html        ← נבנה מ־src/bis-concept.html
├── build.mjs           עוטף את קבצי src במסמך HTML שלם
├── modern.css          שכבת UI מודרנית משותפת לכל מסכי הדמו
├── design/             לוח הכיוונים הוויזואליים (Design Components)
└── src/
    ├── bis-live-customer.html      צד הלקוח
    ├── bis-business-inbox.html     טאב הפניות        ─┐
    ├── bis-business-broadcast.html טאב השידור         ├─ מקורות
    ├── bis-business-editor.html    טאב הפרופיל       ─┘
    ├── bis-business-app.html       ← נוצר ע"י stitch.mjs
    ├── bis-concept.html            מסמך המיקוד
    ├── stitch.mjs                  מרכיב את שלושת הטאבים לאפליקציה אחת
    ├── apply-super.mjs             שכבת העיצוב "תיאבון" — טוקנים, מצב כהה, גיליון "המראה שלך"
    └── apply-naki.mjs              (היסטורי) שכבת העיצוב הקודמת, "נקי"
```

## בנייה

```bash
cd src && node stitch.mjs && cd ..   # מרכיב את אפליקציית העסק משלושת המקורות
node src/apply-super.mjs             # מחיל את שכבת העיצוב על הלקוח, העסק, המסמך ודף הבית
node build.mjs                       # עוטף את קבצי src לדפים עצמאיים בשורש
```

> **חשוב:** אין לערוך את `src/bis-business-app.html` ידנית — הוא נוצר. עורכים את שלושת קבצי המקור ומריצים מחדש את שלושת השלבים.
> `stitch.mjs` חותך את המקורות לפי עוגנים בתוכן (לא לפי מספרי שורות), כך שריסטייל לא שובר אותו.
> `apply-super.mjs` אידמפוטנטי: כל מה שהוא מוסיף יושב בין סמני `SUPER:` ומוחלף בכל הרצה.

## שפת העיצוב — "תיאבון"

עכשווית, חמה ובולטת — לפי עקרונות SuperUI:

- **צבע טעם אחד מניע הכול** — כפתורים, מצבים נבחרים, אייקונים וגרדיאנט הקריאה לפעולה. ברירת המחדל **פפריקה** `#E64A19`; אפשר להחליף ל־פטל, בזיליקום, חציל או אוכמניות, וכל האפליקציה נצבעת מחדש בזמן אמת.
- **דחיפות** `#D61F69` — טיימרים שעומדים להיגמר, ממתינות, מחיקה. סמנטי, לא מותג.
- **מצב בהיר וכהה** — רקע שמנת חם `#FFF7F2` / חום־לילה `#140E0C`. ברירת המחדל לפי המערכת.
- **גיליון "המראה שלך"** (כפתור הפלטה בכל מסך) — תצוגה מקדימה חיה, מתג שמש/ירח, דוגמיות צבע, גודל טקסט (קטן · רגיל · גדול · ענק) וסגנון (מעוגל · רך · חד). השינויים נאספים בפס "● N שינויים · ביטול · סקירה", ונשמרים רק אחרי מסך סקירה. הבחירה נשמרת ב־localStorage ומשותפת לכל הדפים.
- **כותרת גדולה ← כותרת קומפקטית** — כל מסך נפתח בכותרת גדולה ותת־כותרת, ובגלילה היא מתכווצת לפס עליון מטושטש.
- **פרופיל העסק** — כותרת פרופיל עם טבעת התקדמות, ועריכות שנאספות כטיוטה: הפס סופר שדות ששונו, "סקירה" מציגה ישן ← חדש לפני פרסום, ו"ביטול" מחזיר לגרסה המפורסמת.
- **מעמעמים, לא מסתירים** — יום סגור או שידור כבוי משאירים את השדות גלויים ב־40% שקיפות.
- גופן **Rubik** 400–800, כרטיסים מעוגלים (24px), צל רך אחד, וכפתורי גרדיאנט עם זוהר.

## סטטוס

גרסת דמו לצורך תיקוף הרעיון — לא מוצר. אין בק־אנד, אין משתמשים אמיתיים, ואין תשלומים.

## שכבת העיצוב המודרנית

`modern.css` היא שכבת override משותפת לדפי הדמו: קנבס בהיר ונקי, טיפוגרפיה שחורה חזקה, הדגשה כתומה מרוסנת, כרטיסים עם קווי מתאר במקום glow/gradient, פקדים קומפקטיים, יעדי מגע של 44px ומצבי focus/contrast/reduced-motion נגישים. `build.mjs` מוסיף אותה אוטומטית לדפים שנבנים מ־`src/`.
